# VerificaAI
Aplicação web que verifica conteudo de sites de midia/blogs com um sistema de ranqueamento

## Como funciona

A partir de filtragem e escolha de usuario, VerificaAI realiza uma busca em sites escolhidos
resumindo suas informações e julgando sua confiabilidade

## Sistema de confiabilidade

VerificaAI julga a confiabildiade de uma postagem a partir de varios fatores:

- Autenticidade do autor 
- Autenticidade do site
- Referência cruzada

## Tecnologias

- HTML
- CSS
- JS

## Prova de Conceito

Os resultados, as fontes atribuídas, as datas, as justificativas e as pontuações exibidas são inteiramente fictícios e servem apenas para demonstrar a interface. Os filtros alteram os exemplos apresentados, mas o projeto não consulta notícias reais nem calcula credibilidade.
